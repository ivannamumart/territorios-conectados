Falta conectar el juego

El juego todavía no sabe a qué base de datos conectarse. Haz esto una sola vez:

  1. Abre el archivo js/config.js.
  2. Pega la Project URL de Supabase entre las comillas de SUPABASE_URL.
  3. Pega la Publishable key entre las comillas de SUPABASE_KEY.
  4. Guarda el archivo y recarga esta página.

La guía de publicación explica dónde está cada dato.
